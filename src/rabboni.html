無人機的硬體和標準版完全一樣，照「標準版」的 13 個步驟組好、燒好韌體就可以用。差別只在遙控方式：學生手拿 Rabboni，往前傾無人機就往前飛，往右傾就往右飛；油門、解鎖和降落用電腦鍵盤。電腦上跑一支 Python 程式，負責把 Rabboni 的傾斜翻譯成飛行指令。

步驟

1. 安裝與自我檢查（不用任何硬體）

在終端機執行 pip install bleak pyflix，再執行 python rabboni_flix.py --selftest。看到「自我檢查通過」就代表換算公式沒問題。

2. 只連 Rabboni，練習校正（還不連無人機）

  1. 按 Rabboni 右鍵 1 秒，綠燈閃爍代表藍牙廣播中。
  2. 執行 python rabboni_flix.py --no-drone，視窗上方出現「已連線」。
  3. 校正①：照平常握的方式拿平不動，按 Enter。
  4. 校正②：往前傾約 30 度（像要讓飛機往前飛）不動，按 Enter。
  5. 檢查：往前傾，藍點往上（前）；往右傾，藍點往右。不對就按 C 重來。

為什麼要兩步？Rabboni 不管怎麼握都可以，程式從「拿平」和「往前傾」兩個姿勢，自己推算出哪邊是前、哪邊是右。校正結果會存起來，下次開程式不用重做。

3. 連上無人機，不裝槳測試

  1. 拆掉螺旋槳，裝上電池。
  2. 電腦連上 Wi-Fi flix（密碼 flixwifi），執行 python rabboni_flix.py。
  3. 視窗顯示「已連上 Flix」和電池電壓後，按 A 解鎖，再按 ↑ 幾下加一點油門。
  4. 往前傾 Rabboni：後面兩顆馬達要轉得比前面快（飛機才會往前低頭）。往右傾：左邊兩顆比右邊快。
  5. 按 L 自動降落，確認油門慢慢歸零、自動上鎖。
  6. 關掉 Rabboni 電源，確認程式顯示「Rabboni 斷線 → 自動降落」。

4. 裝槳，第一次飛

  1. 空曠室內，人距離 2 公尺以上，第一次用繩子繫留或低高度。
  2. 按 A 解鎖，用 ↑ 慢慢加油門到離地；Rabboni 保持拿平。
  3. 小角度傾斜 Rabboni 移動，想停就拿平。要降落按 L；危險時按 空白鍵。

安全機制

狀況會發生什麼由誰負責
Rabboni 沒電、跑出藍牙範圍0.6 秒沒資料就自動降落rabboni_flix.py
程式當掉、電腦斷 Wi-FiFlix 1 秒沒收到指令就慢慢降落，降到 0 後自動上鎖Flix 韌體（SF_RC_LOSS_TIME）
手抖傾斜小於 5 度當作沒動程式的死區
傾斜太大預設最多推到 50%（約 15 度）；要大一點用 --max 0.8程式的上限
油門不是 0 就按解鎖拒絕解鎖rabboni_flix.py
機身翻過 120 度馬達停止Flix 韌體

限制：Rabboni 的訊號要經過「藍牙 → 電腦 → Wi-Fi」才到飛機，反應會比手機遙控慢一點，適合慢慢移動和懸停，不適合快速飛行。Flix 只維持姿態、不會定位，拿平時飛機仍會慢慢飄，要用 Rabboni 修正。這支程式還沒有實機飛過，第一次請一定照步驟 3 不裝槳測試。

給學生的原理說明

Rabboni 和無人機上的 GY-91 是同一類感測器（IMU）。靜止時，加速度計量到的只有重力，所以能知道「哪邊是上方」。校正①記下拿平時的上方；校正②往前傾時，上方的方向偏移，偏移的方向就是「前」；把「前」和「上」做外積，就得到「右」。之後每一刻，看上方往「前」偏了多少就是前後傾角，往「右」偏了多少就是左右傾角。
